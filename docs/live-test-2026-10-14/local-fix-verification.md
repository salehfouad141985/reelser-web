# التحقق من إصلاحات التنزيل والروابط — 14 أكتوبر 2026

جرى الاختبار عبر API نسخة الإنتاج المبنية محليًا على `http://127.0.0.1:3100` مع مصادر الوسائط الحقيقية. لم تُرفع هذه التعديلات أو تُنشر على موقع الإنتاج خلال هذا العمل.

## التغييرات

- قبول روابط Instagram المتضمنة اسم الحساب قبل `/p/` أو `/reel/` أو `/reels/` أو `/tv/` وتحويلها إلى المسار المباشر قبل الاستخراج، مع الحفاظ على التحقق من المضيف والبروتوكول.
- تسجيل سطر JSON باسم `download_failure` يحدد المرحلة، وسبب الفشل، ومدة الطلب، ومعرّف العملية. عند فشل المصدر تُضاف مرحلته وحالة HTTP أو رمز الشبكة المسموح به. لا تُسجل روابط الوسائط أو التذاكر أو نصوص الاستثناءات أو الردود.
- إرسال `X-Request-Id` في رد التنزيل لربط الطلب بسجله، والتمييز بين المهلة والإلغاء وانتهاء صلاحية التذكرة أو فقدانها.
- رفض إغلاق استجابة المصدر قبل اكتمالها مباشرة، مع تصنيف خطأ المحتوى، بدل انتظار المهلة.

نجحت الاختبارات الـ84، وESLint، وTypeScript، وبناء الإنتاج. تتضمن الاختبارات حالات رفض HTTP 403 من المصدر، وانتهاء صلاحية التذكرة، والمهلة، والإلغاء، وانقطاع جسم الاستجابة، وعدم تسرب البيانات إلى السجلات.

لم يُختبر MP3 في هذه التجربة ولم يُفك كامل الملفين أو يُقيّم محتواهما بصريًا. نجاح التنزيل محليًا لا يثبت نجاحه من استضافة الإنتاج، ولا يحدد بأثر رجعي سبب الفشل السابق هناك. الخطوة التالية هي نشر التعديلات ثم إعادة نفس الاختبار على الموقع المنشور ومطابقة أي فشل مع سجلاته الجديدة.
